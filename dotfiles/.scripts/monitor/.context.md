# Monitor Hotplug System

Automatic monitor connect/disconnect handling for bspwm + eww.
Supports exactly 2 monitors: eDP-1 (laptop, always present) + one external (HDMI/DP).

## Architecture

```
udev event (DRM change)
  └─> monitor_hotplug_udev.sh  (runs as root, delegates to user)
        └─> monitor_hotplug.sh auto

bspc subscribe monitor_add/monitor_remove
  └─> monitor_watcher.sh  (started from bspwmrc)
        └─> monitor_hotplug.sh connect|disconnect

manual invocation
  └─> monitor_hotplug.sh [auto|connect|disconnect]
  └─> monitor_connected  (shortcut → monitor_hotplug.sh connect)
  └─> monitor_disconnected  (shortcut → monitor_hotplug.sh disconnect)
```

Two trigger paths exist for redundancy: udev catches hardware events early,
`bspc subscribe` catches events bspwm processes internally.

## Files

| File | Description |
|------|-------------|
| `monitor_hotplug.sh` | Main script. Detects state, migrates windows, toggles xrandr, relaunches eww. |
| `monitor_watcher.sh` | Long-running daemon. Listens to `bspc subscribe monitor_add monitor_remove` and calls hotplug script. Started from bspwmrc. |
| `monitor_hotplug_udev.sh` | Root-level wrapper for udev. Runs `monitor_hotplug.sh` as the logged-in user with proper X/DBUS env vars. |
| `95-monitor-hotplug.rules` | Udev rule. Fires on `ACTION=="change", SUBSYSTEM=="drm"`. Must be copied to `/etc/udev/rules.d/`. |
| `monitor_connected` | Convenience wrapper → `monitor_hotplug.sh connect` |
| `monitor_disconnected` | Convenience wrapper → `monitor_hotplug.sh disconnect` |

## Disconnect Flow

1. Migrate windows 1:1 — external workspace N → eDP-1 workspace N
2. `xrandr --output <ext> --off` to disable the output
3. Wait 1.5s for X/bspwm to deregister
4. Clean up orphan desktops (any beyond 10 on eDP-1)
5. Relaunch eww (regenerates `_monitors.yuck` for single monitor)

## Connect Flow

1. `xrandr --output <ext> --auto --left-of eDP-1` to activate
2. Wait for bspwm to register the new monitor
3. Create workspaces 1-10 on external, ensure 1-10 on eDP-1
4. Relaunch eww (regenerates `_monitors.yuck` for both monitors)

## Concurrency

Uses `flock` inside a subshell `( flock ... ; main ) 200>lockfile` so the lock fd
is never inherited by eww daemon or other long-lived child processes. This was a
specific fix — `exec fd>` leaked to eww/playerctl/fullscreen_watcher and caused
subsequent runs to see a stale lock.

## Installation (requires sudo)

```bash
sudo cp ~/.scripts/monitor/95-monitor-hotplug.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
```

## Logs

All activity logged to `/tmp/monitor_hotplug.log`. Udev wrapper logs to `/tmp/monitor_hotplug_udev.log`.
